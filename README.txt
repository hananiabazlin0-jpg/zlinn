BAZLIN — PERSONAL COMPANY PROFILE
================================

Files:
- index.html
- style.css

How to use:
1. Extract the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. No server, XAMPP, Laragon, PHP, or database is required.
4. The website is responsive and works on laptop and mobile.

Personalize:
- Replace the placeholder Email / LinkedIn / Instagram links in index.html.
- The "HB" portrait area can later be replaced with a real profile photo.
- Google Fonts are loaded online; the site still works offline with fallback fonts.
